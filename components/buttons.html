Components

Buttons

Two button styles. Primary (filled Berry) is for the main action in a section, like “View Final Prototype.” Secondary (Moss outline) is for supporting actions, like “Back to Projects.” Use no more than one primary button per section.

Live Demo

The first button in each row is live: hover it, or tab to it to see the focus ring. The others are fixed in the hover and disabled states from Figma. Switch to Dark Mode in the navbar to see the dark variants.

Accessibility Guidelines

  • 4.1.2Use <button> for actions on the page and <a href> for anything that goes to another page. Both get the same .btn-ds look, but assistive technology announces them differently.
  • 2.4.4Write labels that say what happens (“View Final Prototype,” “Back to Projects”), not “Click here.” When several buttons share a label, such as “Download SVG,” add an aria-label that names the item.
  • 1.4.3Label contrast meets AA in every enabled state: 6.4:1 on Berry, 8.5:1 on Berry Dark and 5.2:1 for Moss on Warm Linen. In Dark Mode the label switches to Forest Night (8.3:1 on Wild Rose), because Warm Linen there would be only 2.0:1.
  • 1.4.11The secondary border (Moss, 5.2:1 against the page) meets the 3:1 minimum for interface parts.
  • 2.4.7Every button shows a visible focus ring for keyboard users. Never remove it with outline: none unless it is replaced.
  • 4.1.2Disable a <button> with the disabled attribute so it is skipped by the keyboard and announced as unavailable. For a link styled as a button, use aria-disabled="true" and tabindex="-1". Disabled controls are exempt from contrast rules, but explain nearby why an action is unavailable.
  • 2.5.8Buttons are at least 59px tall, well over the 24px minimum target size, and keep 8px or more between neighbors.
  • 3.2.5When a button opens a new tab, say so: add a visually hidden “(opens in a new tab)” and mark the external-link icon aria-hidden="true".
  • 2.3.3The color transition and press nudge are turned off when the visitor has asked for reduced motion.
