Foundations

Typographical Hierarchy

Bricolage Grotesque + Figtree

Base: 18px = 1rem
Headings step down by roughly 1.2 (Minor Third)
Headings use a 1.2 line height; body text uses 1.6

Headings

Headings use Bricolage Grotesque Bold. H1 is Deep Forest; H2 through H4 are Moss, so section titles read as one family under the page title.

H1 – Heading One

The page title. Use once per page, for the project or page name.

  • font-family: "Bricolage Grotesque", sans-serif;
  • font-size: 2.5rem; /* 45px */
  • font-weight: 700;
  • line-height: 54px; /* 1.2 */
  • letter-spacing: 0;
  • color: Color/Text/Heading;

H2 – Heading Two

Major section titles, such as Research, Interviews or Prototype.

  • font-family: "Bricolage Grotesque", sans-serif;
  • font-size: 2.0556rem; /* 37px */
  • font-weight: 700;
  • line-height: 45px; /* 1.22 */
  • letter-spacing: 0;
  • color: Color/Text/Subheading;

H3 – Heading Three

Subsections within a section, such as Preliminary Research or Literature Review.

  • font-family: "Bricolage Grotesque", sans-serif;
  • font-size: 1.7222rem; /* 31px */
  • font-weight: 700;
  • line-height: 37px; /* 1.19 */
  • letter-spacing: 0;
  • color: Color/Text/Subheading;

H4 – Heading Four

Column headings and small groups, such as Problem, Solution and Outcome.

  • font-family: "Bricolage Grotesque", sans-serif;
  • font-size: 1.4444rem; /* 26px */
  • font-weight: 700;
  • line-height: 31px; /* 1.19 */
  • letter-spacing: 0;
  • color: Color/Text/Subheading;

Body Text

Everything that isn’t a heading uses Figtree. All body styles share the 18px size and 29px line height (1.6), except Small and Eyebrow.
