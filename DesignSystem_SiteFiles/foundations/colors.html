Foundations

Color Palette

A forest-inspired palette with a Light Mode and a Dark Mode. Raw colors live in the Primitives collection; components never use them directly. They use the Tokens collection, which maps each job (page background, heading, button) to a primitive for each mode.

Primitives

Each contrast ratio is measured against that mode’s page background (Warm Linen or Forest Night). WCAG AA needs 4.5:1 for body text and 3:1 for large text and interface parts.

Dark Mode Button Text

The Figma token maps Color/Text/Button Text to Warm Linen in both modes. On the Wild Rose button that is only 2.0:1, so in Dark Mode the site uses Forest Night (8.3:1) instead.

Dark Mode Secondary Border

The Figma token maps the secondary button border to Forest Night, the same color as the dark page, so the button would have no visible edge. The site uses Fern, matching the Moss border in Light Mode.

Sage Mist Value

DESIGN.md lists Light Mode/Sage Mist as #F6F3EA under Color Tokens, but the Primitives collection and the Figma swatch use #DDE6D5. The site uses #DDE6D5 so sections stand out from the page.

Never Color Alone

Color is never the only signal. Links are underlined, the active nav link changes weight (500 to 900), and disabled buttons use the disabled attribute as well as a gray fill.
