Anatomy

  • Container: a 100px tall bar on the page background, with the logo and links pushed to opposite ends.
  • Navbar logo: the 64px monogram, then the brand name and tagline stacked 6px apart. The whole lockup links home.
  • Nav links: four links 45px apart. The current page is heavier and darker.
  • Hamburger: below 992px it replaces the links and opens them in a vertical list, and the logo shows as the mark alone. The name and tag stay in the code, visually hidden, so screen readers still announce the link.

Accessibility Guidelines

  • 1.3.1Wrap the bar in a <nav> with an aria-label (for example “Main”), so screen reader users can jump to it and tell it apart from other navigation.
  • 2.4.1Put a “Skip to main content” link before the navbar. It stays hidden until it receives keyboard focus.
  • 4.1.2Mark the current page with aria-current="page", not only with the heavier weight, so assistive technology announces it.
  • 1.4.1The active link is shown by weight (500 to 900) as well as color, so it doesn’t rely on color alone.
  • 4.1.2The hamburger is a real <button> with aria-label="Toggle navigation", aria-controls and aria-expanded, which Bootstrap updates as the menu opens and closes. Its icon is aria-hidden.
  • 1.4.3Link text meets AA in both modes: Charcoal Bark on Warm Linen is 12.8:1 and Birch on Forest Night is 13.8:1. The Berry hover is 6.4:1.
  • 2.4.7Every link and the hamburger show a visible focus ring (a 3px Berry outline with a page-colored gap) when reached by keyboard.
  • 2.5.8The hamburger is 65 × 54px and each link is at least 44px tall in the open mobile menu, so they are easy to tap.
  • 1.1.1The logo image has empty alt text because the name beside it already labels the link. When the logo appears alone, give the link an aria-label such as “Braeden Huff, home.”
  • 2.4.3Keep the DOM order the same as the visual order (logo, links, theme switch) so tabbing follows what people see.
